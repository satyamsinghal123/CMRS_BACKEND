CMRS UPDATED PROJECT - SETUP

Important: The ZIP contains source code only. Do not copy a .env file with real secrets into source control.

BACKEND (Windows PowerShell)
1. Open the backend folder in VS Code.
2. Activate your existing venv, if present: .\venv\Scripts\Activate.ps1
3. Install dependencies if needed: pip install -r requirements.txt
4. Make sure PostgreSQL is running and the backend .env has the correct DB_NAME, DB_USER, DB_PASSWORD, DB_HOST and DB_PORT.
5. Run: python manage.py migrate
6. Run: python manage.py seed_demo
7. Run: python manage.py check
8. Run: python manage.py runserver

FRONTEND (new terminal)
1. Open the frontend folder.
2. Run: npm install
3. Check frontend/.env.example; if needed create frontend/.env with VITE_API_URL=http://127.0.0.1:8000/api
4. Run: npm run dev
5. Open the Vite URL (normally http://localhost:5173) and sign in.

Dashboard notes:
- Dashboard values are daily values for the current local date, except outstanding loans and pending discrepancies.
- seed_demo is intended only for local/demo data. It creates or refreshes named demo rows and moves named demo transactions to today's date. Do not run it against production data.
- Opening /api/dashboard/summary/ directly in a browser without a JWT token is expected to return 401. Test it from the logged-in frontend or send Authorization: Bearer <access_token>.
- Frontend role-based navigation is a convenience, not a security boundary. Backend permissions remain authoritative.
